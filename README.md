# VisionAttend - Face Detection Based Attendance System 🎯

A smart attendance tracker using Machine Learning + Flask + ReactJS.

## 🧠 Backend (Python + Flask)
- Face recognition using OpenCV + `face_recognition`
- API endpoint for real-time attendance
- Attendance saved in `attendance.csv`

## 🌐 Frontend (React)
- Live webcam feed using `react-webcam`
- Capture + upload to backend
- Displays current attendance logs
